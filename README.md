# CCAO-F Study Guide

A study guide for the **Claude Certified Associate – Foundations (CCAO-F)** exam, built entirely from Anthropic's official documentation.

## Features

- **Anthropic official sources only** — every claim cites its source (docs.claude.com, platform.claude.com, anthropic.com, support.claude.com)
- **7 domains in prose + diagrams** — Mermaid flowcharts and tables, not bare bullet lists
- **Common pitfalls** summarized at the end of each domain
- **Aligned with CCAO-F Blueprint v1.0** (effective July 2026)

## Who is this for

- Business and productivity users preparing for the CCAO-F exam
- Anyone who wants to use Claude.ai features effectively (Projects, Artifacts, Memory, Skills, Code Execution, Research mode)
- Note: API, SDK, and MCP are **out of scope** (those belong to the Claude Architect / Developer certifications)

## Contents

- Exam overview, scoring, and blueprint
- Domains 1–7 (Task Statements: knowledge, skills, and decision principles)
- Sample Questions
- Hands-on exercises
- Appendix (concepts, in-scope / out-of-scope topics, preparation tips)
