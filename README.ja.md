# CCAO-F 学習ガイド

**Claude Certified Associate – Foundations (CCAO-F)** 試験の学習ガイド。Anthropic 公式ドキュメントのみを典拠として構成しています。

## 特徴

- **Anthropic 公式情報のみ** — すべての主張に出典（URL）を明記（docs.claude.com / platform.claude.com / anthropic.com / support.claude.com）
- **7 ドメインを散文＋図解** — 箇条書きでなく、Mermaid 図とテーブルで理解を深める
- **各ドメイン末尾に「陥りやすい罠」** — よくある誤答パターンを集約
- **CCAO-F Blueprint v1.0（2026 年 7 月発効）に準拠**

## 対象読者

- CCAO-F 受験を予定するビジネス・生産性ユーザー
- Claude.ai の製品機能（Projects, Artifacts, Memory, Skills, Code Execution, Research mode）を使いこなしたい方
- ※ API / SDK / MCP は Claude Architect / Developer 認定の範囲のため、本ガイドでは扱いません

## 内容

- 試験の概要・採点・ブループリント
- Domain 1〜7 の Task Statement ごとの解説（知識・スキル・判断指針）

- 演習問題
- 付録（技術と概念・試験範囲・対策推奨事項）
